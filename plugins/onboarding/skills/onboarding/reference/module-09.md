# Module 9 — Maak je eerste skill

Doel: een herbruikbare werkwijze maken en opnieuw kunnen toepassen.
Leg uit: de agent organiseert een proces en tools; de skill beschrijft een herbruikbare
aanpak; één losse prompt is nog geen geïnstalleerde skill.

Bied drie voorbeelden en ruimte voor een eigen idee:

1. [Schrijf in mijn tone of voice](skill-tone-of-voice.md).
2. [Maak complexe informatie begrijpelijk](skill-begrijpelijk.md).
3. [fact-checker](skill-feiten.md).

Wil de medewerker daarna de Onderwijsloket Fact Check Agent bouwen, raad dan
fact-checker aan: de zelfgemaakte skill wordt in module 10 aan die agent toegevoegd.
De andere skillkeuzes blijven mogelijk.

Lees de gekozen definitie en gebruik de volledige SKILL.md-tekst als vertrekpunt.
Bespreek de gewenste invoer, uitvoer en één realistische test. Gebruik de beschikbare
skillcreator of interface; laat naam en activatiebeschrijving aansluiten op de taak.
Bij het stijlvoorbeeld zijn twee of drie geschikte eigen teksten nodig, zonder
gevoelige gegevens. Voeg die alleen toe als de host de bronnen bij hergebruik kan laden.

Help de skill daadwerkelijk opslaan/installeren. Voer de test via de opgeslagen
skill uit en laat een tweede toepassing zien, zodat hergebruik herkenbaar is.
Bewaar een veilige verwijzing naar de werkelijk gemaakte skill, zodat die in de
volgende module expliciet geselecteerd kan worden. Gebruik de grensproef uit de referentie om ontbrekende bronnen of ongeschikte invoer
te beoordelen. Verbeter en test zo nodig opnieuw. Geen verborgen installatie van
andere plugins of skills als vervanging van het gekozen leerdoel.

Afronding: de skill is aangemaakt of geïnstalleerd en eenmaal succesvol toegepast;
een herhaalde toepassing is getoond of door de gebruiker bevestigd. Alleen de
Markdowntekst in de chat betekent nog geen afgeronde module.
